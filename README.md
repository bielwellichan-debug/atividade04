# 📖 Atividade 04 - HTML e CSS
Nesta atividade nos foi proposto que criassemos um site em formato de Biografia para uma celebridade. Minha escolha foi Guilherme Briggs, famoso dublador brasileiro.

## 🤔 O que foi trabalhado?
Foi trabalhado nessa atividade a nossa capacidade de usar o CSS de maenira um pouco mais avançada com relação a Atividade 03.

## 💭 Por que o CSS era mais avançado?
Por conta que trabalhamos alguns comandos mais complexos e mais estilistas. Além disso, foi necessário que criassemos uma página somente para o CSS dentro de uma pasta somente para páginas (Que já vinha sendo trabalhado antes).
